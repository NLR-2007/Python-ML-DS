## 🚀 How to Use This Repository

### 1. Clone the repository

```bash
git clone https://github.com/NLR-2007/Python-ML-DS.git
```

### 2. Move into the project folder

```bash
cd Python-ML-DS
```

### 3. Open the notebook

You can open the notebook using:

- Jupyter Notebook
- JupyterLab
- VS Code
- Google Colab

```bash
jupyter notebook python_basics.ipynb
```
